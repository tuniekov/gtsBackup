gtsBackup 1.0.1-beta
- Клиент перенесён в пакет: core/components/gtsbackup/client/, описание протокола — core/components/gtsbackup/client/protocol.md.
- Клиент не выполняется через веб (только командная строка).
- Пакет не создаёт групп ресурсов; исключения по умолчанию без чужих компонентов.
- Клиент хранит бекапы цепочками: <время полного>/full и diff-<время> рядом; list — дерево и сводка.
- add --time ставит задачу в Планировщик (SYSTEM из консоли администратора), --now — первый бекап; php.path.
- Кнопка «Скачать клиент» и ссылка на zip клиента в окне создания токена.
